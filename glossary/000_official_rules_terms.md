## 1. Purpose

This file is the dedicated glossary surface for official rules terminology.

It is intentionally separate from strategic deckbuilding terminology so YGOBrain does not blur official game terms with project shorthand.

## 2. Scope

This glossary covers:

- official or rules-facing terminology
- terms that should be checked against official TCG sources where practical
- future links to rules modules and terminology tests

This glossary does not cover:

- strategic deckbuilding shorthand
- archetype-specific deck roles
- analytics metrics
- unofficial simulator language

## 3. Current Status

No official rules terms have been drafted in this glossary yet.

Future rules terms should usually be added only after the relevant rules module exists or after Admin approves a source-backed terminology entry.
